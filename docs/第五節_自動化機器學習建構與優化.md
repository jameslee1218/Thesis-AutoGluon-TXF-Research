# 第五節：自動化機器學習建構與優化 — 依輸入／訓練／驗證層的完整說明

依照「輸入層 → 訓練層 → 驗證層」的邏輯，整理成可直接用於論文第五節的說明如下。

---

## 一、輸入層：特徵如何組合與輸入

### 1.0 原始輸入的週期篩選（設計前提）

**原始技術指標在進入流程前，強制篩選為週期 ≤ 5**，目的在於：

- 單日早盤截點前僅有約 15～45 筆分鐘資料（依截點 0900／0915／0930 而定）
- 若使用週期 14、20 等較長指標，前幾筆會出現 NaN，影響後續學習
- 將所有技術指標限制為**週期 5 以下**，可確保**至遲於第 5 筆資料**即有有效值，後續敘述統計與模型訓練時不會因缺值而丟失樣本

此篩選於 `indicators_complete` 或 `technical_indicators_data_extracted` 產出階段完成，再進入截點切分與合併流程。

---

### 1.1 輸入組合的兩種方式

| 類型 | 說明 | 資料來源 | 輸出路徑 |
|------|------|----------|----------|
| **壓縮版（compressed）** | 先經 autoencoder 壓縮，再彙總為日頻特徵 | `output2/year_*/` + `dataset/{cutoff}/` | `data/autogluon_ready/{cutoff}/merged_for_autogluon_{cutoff}.csv` |
| **未壓縮版（uncompressed）** | 直接對原始技術指標做日頻彙總，不做壓縮 | `dataset/{cutoff}/` 或 `indicators_complete/` | `data/autogluon_ready_uncompress/{cutoff}/merged_for_autogluon_{cutoff}.csv` |

---

### 1.2 壓縮版輸入組合流程（逐步）

**Step 1：截點前分鐘資料**

- 來源：`data/dataset/{0900,0915,0930}/` 的 1 分鐘 K 線與技術指標（已為週期 ≤ 5）
- 時間篩選：依截點保留「當日 ≤ 截點時間」的列
  - 0900：`datetime.time <= 09:01:00`
  - 0915：`datetime.time <= 09:16:00`
  - 0930：`datetime.time <= 09:31:00`

**Step 2：壓縮特徵載入**

- 來源：`data/output2/year_YYYY/{INDICATOR}/compressed_data/*_compressed.csv`
- 7 群組：ADX_DMI、AROON、BBANDS、MACD、STOCH、STOCHF、STOCHRSI
- 依年度對齊：某日使用該日所屬年份的壓縮結果（避免未來資訊洩漏）

**Step 3：日頻彙總（敘述統計）**

- 對截點前分鐘資料，依日期分組，計算五個敘述統計：`mean`、`std`、`min`、`max`、`median`
- 欄位命名：`{欄位名}_{stat}`，例如 `ADX_DMI_compressed_0_mean`、`STOCH_compressed_0_median`

**Step 4：移除原始指標（僅壓縮版）**

- 壓縮版會刪除原始技術指標欄位（`merge_output2_for_autogluon.py` 中 `ORIGINAL_INDICATOR_COLUMNS` 所定義），只保留壓縮特徵
- 目的：避免重複使用原始指標，讓模型只依賴壓縮後特徵

**Step 5：合併目標變數**

- 來源：`data/target/y.xlsx` 或 `y.csv`
- 欄位：`afternoon_return_0900` / `0915` / `0930`（依截點）
- 若為 log 報酬，合併時轉為 simple return，並命名為 `target_return`

**Step 6：前處理**

- 捨棄 year < 2013 的樣本（`MIN_YEAR = 2013`）
- 移除常數特徵（`nunique <= 1`）
- 對含 NaN 的列做 `dropna()`（訓練時）

---

### 1.3 未壓縮版輸入組合流程（逐步）

**Step 1～2**：與壓縮版相同，讀取截點前分鐘資料（來源為 `dataset/{cutoff}/` 或 `indicators_complete/`）

**Step 3：直接對原始技術指標做日頻彙總**

- `build_uncompressed_autogluon.py` 使用 `numeric_cols = work.select_dtypes(include=[np.number]).columns.tolist()`，**動態取用資料中所有數值欄位**
- 實際欄位數與名稱依上游資料而定；若已篩選週期 ≤ 5，則為對應之週期 3、5 等指標（如 `STOCH_K_5`、`BBANDS_upper_5` 等）
- 同樣計算 `mean`、`std`、`min`、`max`、`median`

**Step 4～6**：與壓縮版相同（合併 Y、前處理）

---

### 1.4 送入 AutoGluon 前的欄位處理

- 移除：`date`、`datetime`、`year`（避免洩漏時間資訊）
- 移除：含 NaN 的列（`dropna()`）
- 保留：所有數值特徵 + `target_return`（label）

## 二、訓練層：參數優化與訓練設定

### 2.1 優化目標（eval_metric）的兩種選擇

| 設定 | eval_metric | 說明 |
|------|-------------|------|
| **RMSE 版** | `"rmse"` | 最小化均方根誤差，AutoGluon 內建 |
| **Sharpe 版** | `sharpe_scorer_ag_reg` | 最大化年化 Sharpe，自訂 scorer |

### 2.2 RMSE 優化（設定 1、2）

- 使用 AutoGluon 預設 `eval_metric="rmse"`
- 訓練時以驗證集 RMSE 選模型與超參數

### 2.3 Sharpe 優化（設定 3、4）

- 自訂 scorer：`annualized_sharpe_reg`
- 邏輯：
  1. 依預測值決定部位：`pred > 0.0001` 做多、`pred < -0.0001` 做空
  2. 策略報酬 = 部位 × 實際報酬
  3. 扣除交易成本：`COST_PER_TRADE = 0.0005`（每筆 0.05%）
  4. 年化 Sharpe = `(mean_return / std_return) × √252`
- 訓練時以驗證集 Sharpe 選模型與超參數

### 2.4 訓練時間與資源

| 參數 | 值 | 說明 |
|------|-----|------|
| `time_limit` | 3600 秒 | 單一 roll 訓練時間上限 |
| `ag_args_fit` | `{'num_gpus': 1}` 或 `{'num_gpus': 0}` | 依 GPU 是否可用 |

### 2.5 模型與超參數搜尋

| 參數 | 值 | 說明 |
|------|-----|------|
| `presets` | `"best_quality"` | 品質優先，會嘗試較多模型與超參數 |
| `dynamic_stacking` | `True` | 啟用動態 stacking |
| `hyperparameters` | 未顯式指定 | 由 AutoGluon 依 preset 自動搜尋 |

### 2.6 訓練年數與滾動設定

- `TRAIN_YEARS_LIST = [2, 3, 4, 5]`
- 每個 train_years 獨立跑一輪滾動
- 單一 roll：用連續 N 年訓練，預測第 N+1 年

### 2.7 訓練層參數總覽

| 參數 | 值 |
|------|-----|
| `label` | `"target_return"` |
| `problem_type` | `"regression"` |
| `time_limit` | 3600 |
| `presets` | `"best_quality"` |
| `dynamic_stacking` | `True` |
| `eval_metric` | `"rmse"` 或 `sharpe_scorer_ag_reg` |
| `ag_args_fit` | `{'num_gpus': 1}` 或 `{'num_gpus': 0}` |

## 三、驗證層：輸出與如何得出結論

### 3.1 滾動驗證邏輯（逐步）

**Step 1：決定預測年**

- 對每個 `train_years`（2, 3, 4, 5），找出可預測的年份
- 條件：該年之前連續 N 年都有資料
- 範例：train_years=5 時，可預測 2017～2023

**Step 2：切分訓練／測試**

- 訓練集：`required_train_years = range(predict_year - TRAIN_YEARS, predict_year)`
  - 例：預測 2020，train_years=5 → 訓練 2015–2019
- 測試集：`predict_year` 整年
- 不做隨機抽樣，依時間切分，避免未來資訊進入訓練

**Step 3：資料量檢查**

- 訓練集至少 50 筆
- 測試集至少 10 筆
- 不足則跳過該 roll

**Step 4：訓練與預測**

- 用訓練集訓練 TabularPredictor
- 用測試集做 `predictor.predict(test_ag)`，得到 `pred_best`

**Step 5：事後評估**

- 不論 eval_metric 為何，皆計算：
  - RMSE：`√mean((y_pred - y_true)²)`
  - Sharpe：`compute_sharpe_backtest(y_true, y_pred)`

### 3.2 如何選出「最佳模型」

- **訓練階段**：AutoGluon 依 `eval_metric` 在驗證集上選最佳模型
- **儲存**：`predictor.model_best` 即該 roll 的最佳模型名稱
- **預測**：`predictor.predict(test_ag)` 預設使用 `model_best`

### 3.3 輸出檔案與用途

| 檔案 | 用途 |
|------|------|
| `predictions.csv` | 最佳模型預測：`date`, `target_return`, `pred` |
| `predictions_all_models.csv` | 所有模型預測，可比較不同模型 |
| `metrics.json` | 該 roll 的 rmse、sharpe、best_model、train_period |
| `leaderboard.csv` | AutoGluon 驗證集排名 |
| `leaderboard_with_metrics.csv` | leaderboard + 測試集 rmse_test、sharpe_test |
| `models_performance.csv` | 各模型在測試集的 rmse、sharpe |
| `feature_importance_all_models.csv` | 各模型特徵重要性 |
| `summary_train{N}y.csv` | 該 train_years 下各 roll 彙總 |
| `summary_all_train_years.csv` | 所有 train_years 合併彙總 |

### 3.4 如何得出「該模型最好」的結論

**單一 roll：**

- 依 `eval_metric`：RMSE 版選驗證集 RMSE 最低；Sharpe 版選驗證集 Sharpe 最高
- 事後檢視：`leaderboard_with_metrics.csv` 的 `rmse_test`、`sharpe_test` 可看測試集表現

**跨 roll 比較：**

- 讀 `summary_all_train_years.csv`，依 `train_years`、`cutoff` 分組
- 比較各設定的平均 rmse、sharpe
- 讀 `models_performance_all_train_years.csv` 比較不同模型在不同年份的表現

**跨設定比較（四種設定）：**

- 1.compressed RMSE、2.uncompressed RMSE、3.compressed sharpe、4.uncompressed sharpe
- 比較維度：壓縮 vs 未壓縮、RMSE vs Sharpe
- 可依 `summary_all_train_years.csv` 或自建彙總表做比較

### 3.5 特徵重要性分析

- 來源：`feature_importance_all_models.csv`
- 計算對象：RMSE 前 3 名 + Sharpe 前 3 名模型（去重）
- 用途：檢視哪些特徵對預測貢獻較大，支援模型解釋與特徵篩選

### 3.6 驗證層流程總覽

```
對每個 train_years ∈ {2,3,4,5}：
  對每個 predict_year（有足夠連續訓練年）：
    1. 切分 train / test（依年）
    2. 訓練 TabularPredictor（依 eval_metric 優化）
    3. 預測 test，得到 pred_best
    4. 計算 rmse、sharpe（事後評估）
    5. 對所有模型計算 rmse_test、sharpe_test
    6. 輸出 predictions、metrics、leaderboard、feature_importance
  彙總該 train_years 的 summary_train{N}y.csv
彙總 summary_all_train_years.csv、models_performance_all_train_years.csv
```
